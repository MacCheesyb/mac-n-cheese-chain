Locked. Create a wallet with a password, or unlock an existing one.

Prototype only — not audited. Do not use for real funds. v0.4 stores the private key encrypted at rest in this browser with AES-GCM, unlocked by your password (PBKDF2, 100,000 iterations). Balance comes from a local ledger file you load — there is no node yet. If this wallet is the genesis holder in that ledger, the balance is 100,000 R0NI; otherwise it is the ledger balance, or 0. Address here is now the canonical EvoHash-11 address — the same address roni_wallet.py gives for the same key (see evo-hash-11.js). Wallets created by v0.3 with the old interim SHA-512 address are migrated automatically on load, and their ledger entries are rewritten to the new address, so a genesis allocation is not lost. No node or transaction sending yet — sending lives in wallet-app.html in the repo root.
