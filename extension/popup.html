Prototype only — not audited. Do not use for real funds. v0.5 stores the private key encrypted at rest in this browser with AES-GCM, unlocked by your password (PBKDF2, 100,000 iterations). Balance comes from a local ledger file you load — there is no node yet. If this wallet is the genesis holder in that ledger, the balance is 100000.000 R0NI; otherwise it is the ledger balance, or 0. Amounts are integer milli-R0NI (1 R0NI = 1000 milli; smallest unit 0.001 R0NI), exactly as roni_wallet.py since commit e308fee — a legacy ledger with whole-R0NI amounts is migrated x1000 on load. Address here is the canonical EvoHash-11 address — the same address roni_wallet.py gives for the same key (see evo-hash-11.js). Wallets created by v0.3 with the old interim SHA-512 address are migrated automatically on load, and their ledger entries are rewritten to the new address, so a genesis allocation is not lost. Sign a transfer above to get a signed transaction JSON — submit it with testnet/accept_signed_tx.py signed-tx.json. The extension does not send transactions itself. A signed transaction without the "amount_unit": "milli-R0NI" marker is a pre-milli transaction and is rejected, never silently converted.
